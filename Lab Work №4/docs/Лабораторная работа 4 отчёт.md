### Метод GET /v1/ElectronicTypes  
Получить список видов электроники с суммой выдачи за их сдачу и id прикрепленных к ним документов - правил проверки и оценки.  
Если список видов электроники изменится, то возможно дублирование или пропуск элементов при их постраничном просмотре. Чтобы избежать этого, можно проверять, изменилась ли коллекция в ходе итераций при помощи etag.  
#### Описание запроса
##### Параметры запроса  
skip: integer - число пропущенных с начала списка элементов, при его сортировке по id (максимально можно вернуть 100 элементов за запрос)  
top: integer - число возвращённых с начала списка элементов до пропуска skip, при его сортировке по id (максимально можно вернуть 100 элементов за запрос)  
select: string - список возвращаемых полей объектов через запятую. Не должен шифроваться с помошью % encoding  
##### Заголовки запроса  
Authorization - принимает только значение "Bearer <токен авторизации>". В противном случае, будет возвращён ответ с кодом 401 Unauthorized.  
If-None-Match - принимает значение ETag. При указании, делает так, что сервер вернёт список только если посланный ETag данной коллекции не совпадает с ETag данной коллекции на сервере (иначе будет ответ с кодом 304 Not Modified).  
If-Match - принимает значение ETag. При указании, делает так, что сервер вернёт список только если посланный ETag данной коллекции совпадает с ETag данной коллекции на сервере (иначе будет ответ с кодом 412 Precondition Failed).  
##### Тело запроса  
Так как это метод GET, то тело запроса является пустым
#### Описание ответа  
##### Коды ответа  
##### Заголовки ответа  
Content-Type - при успешном ответе (код 200 OK), равен application/json.  
WWW-Authenticate - при коде ответа 401 Unauthorized, содержит строку "Bearer", указывающую, что нужно авторизоваться и получить токен авторизации для использования метода.

### Метод GET /v1/ElectronicTypes/{id}  
Получить вид электроники с суммой выдачи за его сдачу и id прикреплённому к нему документа - правил проверки и оценки  
### Метод GET /v1/Rules/{file_name}  
Получить документ с правилами проверки и оценки товаров по его имени file_name  
### Метод POST /v1/ElectronicTypes
Добавляет новый вид электроники (вместе с суммой выдачи и id прикреплённого к нему документу) из тела запроса в систему  
### Метод POST /v1/Rules  
Загрузить новый документ с правилами проверки и оценки из тела запроса в систему  
### Метод GET /v1/Rules  
Получть список всех документов с правилами проверки и оценки в системе с их именами  
Дополнительно: фильтрация и сортировка  
### Метод DELETE /v1/Rules/{file_name}  
Удалить документ с правилами проверки и оценки из системы (ссылка на него у всех связанных с ним типов электроники становится равна null)  
### Метод PUT /v1/Rules/{file_name}  
Заменить документ с правилами проверки и оценки в системе по его имени file_name
