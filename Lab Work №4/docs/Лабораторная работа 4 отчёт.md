### Метод GET ElectronicTypesApp/ElectronicTypeList  
Получить список видов электроники с суммой выдачи за их сдачу и id прикрепленных к ним документов - правил проверки и оценки  
Дополнительно: фильтрация и сортировка  
### Метод GET ElectronicTypesApp/ElectronicTypes/{id}  
Получить вид электроники с суммой выдачи за его сдачу и id прикреплённому к нему документа - правил проверки и оценки  
### Метод GET ElectronicTypesApp/Rules/{id}  
Получить документ с правилами проверки и оценки товаров по заданному id  
### Метод POST ElectronicTypesApp/ElectronicType
Добавляет новый вид электроники(вместе с суммой выдачи и id прикреплённого к нему документу) из тела запроса в систему  
### Метод POST ElectronicTypesApp/Rules  
Загрузить новый документ с правилами проверки и оценки из тела запроса в систему  
### Метод GET ElectronicTypesApp/RulesList  
Получть список всех документов с правилами проверки и оценки в системе с их идентификаторами  
Дополнительно: фильтрация и сортировка  
### Метод DELETE ElectronicTypesApp/Rules/{id}  
Удалить документ с правилами проверки и оценки из системы (ссылка на него у всех связанных с ним типов электроники становится равна null)  
### Метод PUT ElectronicTypesApp/Rules/{id}  
Заменить документ с правилами проверки и оценки в системе по id
