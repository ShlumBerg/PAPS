### Метод GET /v1/ElectronicTypes  
Получить список видов электроники с суммой выдачи (в рублях) за их сдачу и id прикрепленных к ним документов - правил проверки и оценки.  
Список сортируется по возрастанию id возвращаемых видов электроники.  
Если список видов электроники изменится, то возможен пропуск элементов при их постраничном просмотре. Чтобы избежать этого, можно проверять, изменилась ли коллекция в ходе итераций при помощи ETag.  
#### Описание запроса
##### Параметры запроса  
- skip: integer, необязательный - число пропущенных с начала списка элементов, при его сортировке по id (максимально можно вернуть 100 элементов за запрос, по умолчанию равно 0).  
- maxCount: integer, необязательный - максимальное число возвращённых с начала списка элементов после пропуска skip, при его сортировке по id (максимально можно вернуть 100(если maxCount больше 100, то всё равно выдастся только 100 элементов) элементов за запрос, по умолчанию равно 10).  
- select: string, необязательный - список возвращаемых полей объектов через запятую. Не должен шифроваться с помошью % encoding. При пропуске, вернёт все объекты, доступные текущему пользователю.    
##### Заголовки запроса  
- Authorization: string - принимает только значение "Bearer <токен авторизации>". В противном случае, будет возвращён ответ с кодом 401 Unauthorized.  
- If-None-Match: string, необязательный - принимает значение ETag в кавычках. При указании, делает так, что сервер вернёт список только если посланный ETag данной коллекции не совпадает с ETag данной коллекции на сервере (иначе будет ответ с кодом 304 Not Modified).  
- If-Match: string, необязательный - принимает значение ETag в кавычках. При указании, делает так, что сервер вернёт список только если посланный ETag данной коллекции совпадает с ETag данной коллекции на сервере (иначе будет ответ с кодом 412 Precondition Failed).  
##### Тело запроса  
Так как это метод GET, то тело запроса является пустым
#### Описание ответа  
##### Коды ответа  
- 401 Unauthorized - не предоставлен токен входа в систему, либо, токен нерабочий (возможно, токен просрочен)  
- 400 Bad Request - неверный формат заголовков запроса или неверное значение параметров запросов (не целое число в случае skip и maxCount или несуществующее поле объекта в случае select, или skip или maxCount меньше нуля), либо неизвестный параметр запроса  
- 403 Forbidden - в select указаны поля, недоступные для текущего пользователя, в теле ответа вернётся список этих полей.    
- 304 Not Modified - при указании заголовка If-None-Match, если значение заголовка совпадает с ETag данной коллекции на сервере  
- 412 Precondition failed - при указании заголовка If-Match, если значение заголовка не совпадает с ETag данной коллекции на сервере  
- 200 OK - если получилось успешно вернуть требуемые элементы коллекции (возможно, их будет 0, при пустой коллекции или при некоторых параметрах skip и maxCount).  
##### Заголовки ответа  
- Content-Type: string - равен application/json.  
- WWW-Authenticate: string - при коде ответа 401 Unauthorized, содержит строку "Bearer", указывающую, что нужно авторизоваться и получить токен авторизации для использования метода. Иначе не возвращается.  
- ETag: string - текущий ETag всей коллекции ElectronicTypes на стороне сервера.  
##### Тело ответа  
JSON объект с 3 полями:  
- count: integer - число возвращённых видов электроники  
- totalCount: integer - суммарное число видов электроники в коллекции  
- items: array - список с возвращёнными видами электроники.  
  
Каждый элемент в массиве items представляет собой объект JSON с некоторыми из следующих полей (в зависимости от роли пользователя в системе и значения параметра "select"):  
- id: integer - уникальный идентификатор вида электроники  (доступен всем авторизованным пользователям)  
- name: string - название вида электроники  (доступен всем авторизованным пользователям)  
- ETag: string - текущий ETag данного вида электроники (доступен всем авторизованным пользователям)  
- rule: string - название документа (без % encoding) с правилами проверки и оценки для данного элемента (доступен только ролям "администратор" и "инспектор" системы)  
- price: integer - сумма денег (в рублях), получаемых клиентом за сдачу данного вида электроники (доступен всем авторизованным пользователям)
#### Примеры

### Метод GET /v1/ElectronicTypes/{id}  
Получить вид электроники с суммой выдачи за его сдачу и id прикреплённому к нему документа - правил проверки и оценки  
### Метод GET /v1/Rules/{file_name}  
Получить документ с правилами проверки и оценки товаров по его имени file_name  
### Метод POST /v1/ElectronicTypes
Добавляет новый вид электроники (вместе с суммой выдачи и id прикреплённого к нему документу) из тела запроса в систему  
### Метод POST /v1/Rules  
Загрузить новый документ с правилами проверки и оценки из тела запроса в систему  
### Метод GET /v1/Rules  
Получть список всех документов с правилами проверки и оценки в системе с их именами  
Дополнительно: фильтрация и сортировка  
### Метод DELETE /v1/Rules/{file_name}  
Удалить документ с правилами проверки и оценки из системы (ссылка на него у всех связанных с ним типов электроники становится равна null)  
### Метод PUT /v1/Rules/{file_name}  
Заменить документ с правилами проверки и оценки в системе по его имени file_name
