# Перечень заинтересованных лиц (стейкхолдеров)  
|Стейкхолдер|Описание|
|---|---|
|Клиенты|Клиенты системы, которые с помощью системы получают расценки на технику и сдают б/у технику для получения денег|
|Инспекторы техники|Инспекторы техники(сотрудники магазина или киоска в ТЦ), которые с помощью системы получают инструкции для проверки сданной техники и помечают в системе, можно ли её переработать или продать и количество денег, которое получит клиент за предложение|
|Администратор системы|Администратор системы добавляет новые виды электроники для приёмки и удаляет старые, изменяет правила проверки и оценки для имеющихся в системе видов электроники|
|Разработчики системы|Разработчик системы, который хочет получить требования в понятном для себя виде для их реализации|
|Тестировщики системы|Тестировщики системы, которые хотят получить требования в понятном для себя виде для проверки соответствия им разработанной системы|
|Спонсоры проекта|Спонсоры проекта по созданию и сопровождению рассматриваемой системы могут отменить его, если он не оправдает возложенных ожиданий (прибыль и доля рынка)|
|Правоохранительные органы|Правоохранительные органы могут вынести наказание юридическому лицу - оператору магазинов и нашей системы наказание, если не будет соблюдаться законодательство|
|Конкуренты по сфере утилизации техники|Конкуренты могут намеренно усложнять наше положение на рынке утилизации техники, например, предлагая чересчур выгодные предложения клиентам|
# Перечень функциональных требований  
Для клиентов:  
- Получить список предложений (вид товара и стоимость его приёмки)  
- Получить список мест (магазинов и киосков), куда можно сдать технику  
- Отслеживать статус сданной техники для получения информации о том, приняли её или нет и сколько денег за неё клиент получил
- Вывести полученные от сданной техники деньги на банковскую карту  

Для инспекторов техники:  
- Получить список предложений (вид товара и стоимость его приёмки)  
- Получить по виду техники правила проверки и оценки  
- Ввести в систему рассчитанную оценку стоимости для данного товара, сданного клиентом  
- Отслеживать статус сданной техники для получения информации о том, приняли её или нет и сколько денег за неё клиент получил
- Добавить в систему новый экземпляр сданной клиентом техники
  
Для администраторов системы:  
- Получить список предложений (вид товара и стоимость его приёмки)
- Получить список мест (магазинов и киосков), куда можно сдать товар
- Добавить новый вид электроники (вместе с ценой и правилами проверки и оценки)
- Показать виды электроники, которые не принимались в течение года
- Изменить цену приёмки вида электроники
- Удалить вид электроники
- Изменить правила проверки и оценки для вида электроники
- Добавить магазин или киоск, куда можно сдать товар, в систему
- Удалить магазин или киоск, куда можно сдать товар, из системы

# Перечень сделанных предположений  
- Все магазины компании располагаются в РФ, юридическое лицо зарегистрировано в Москве  
- Всего компания оперирует 50 магазинами электроники в РФ, планируется сотни и тысячи точек сдачи товара
- Планируются принимать одновременно тысячи различных видов техники.
- Старое электронное оборудование, которое не принималось в течение года, удаляется администратором системы вручную (после запроса списка видов электроники, которые не принимались в течение года)
- Система не решает вопросы, связанные с хранением и доставкой техники на место переработки и непосредственно переработки техники
- Перевод денег на карту клиенту должен проводиться с использованием сторонних платёжных систем (ЮКасса и подобные). Для этого используются деньги с расчётного счёта юридического лица - сети магазинов.
- Если товар пришел не в том состоянии, о котором заявлял клиент, то ему даётся 7 календарных дней на возврат товара. Если клиент не вернул его, то товар утилизируется, и клиенту даются деньги за его сдачу согласно изменённому предложению.
- Технику клиент может сдать только лично в магазин или лично в киоск в ТЦ. При этом создаётся запись в системе о том, что техника сдана с уникальным ID и наклейка с этим ID наклеивается на саму технику.
